# Adrián Latorre — sitio personal

Sitio estático listo para GitHub Pages.

## Estructura

- `index.html` — página principal.
- `books.html` — libros recomendados.
- `podcasts.html` — episodios y podcasts recomendados.
- `videos.html` — vídeos que merece la pena ver.
- `people.html` — personas y canales que sigo.
- `freelancing/index.html` — landing de servicios de Meta Ads.
- `assets/images/` — imágenes del sitio.

## Publicación

Sube el contenido de esta carpeta a la raíz del repositorio usado por GitHub Pages. Si utilizas un dominio personalizado, conserva o añade el archivo `CNAME` con el dominio exacto configurado en GitHub Pages.
